# Classroom Quiz controls

Add two teacher controls without changing scoring or question selection:

- After a question is revealed, show an **Explanation** button that opens the existing worked-solution window for that exact paper question.
- Keep explanations unavailable while teams are still answering.
- Add **End quiz** throughout active play; require confirmation, then show results using scores already earned.

## Expected behavior

Ending early does not score an unanswered current question. If the current question has already been revealed, its awarded points remain included.
